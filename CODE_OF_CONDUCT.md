# Code of Conduct

We want this project to be a welcoming, technical, and productive place for contributors.

## Expected behavior

- Be respectful and constructive.
- Focus discussion on the project, reproducible technical issues, and useful feedback.
- Respect different experience levels, platforms, languages, and backgrounds.
- Protect privacy and sanitize logs or session examples before posting.

## Unacceptable behavior

- Harassment, personal attacks, threats, or discrimination.
- Spam, deliberate disruption, or misleading technical claims.
- Publishing API keys, private prompts, proprietary code, customer data, or other sensitive information.

## Enforcement

Maintainers may edit, hide, or remove content and restrict participation when needed to protect the project and its community.

If you see a problem, report it through the repository's GitHub moderation or reporting tools.
