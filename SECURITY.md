# Security Policy

## Supported versions

The latest public release is the primary supported version.

## Reporting a security or privacy issue

Please do not publish API keys, private prompts, proprietary code, customer data, or sensitive Codex session content in public issues.

When reporting a problem, provide only the minimum sanitized information needed to reproduce it.

Useful details include:

- Operating system
- Python version
- Codex version, if known
- Project release
- Sanitized reproduction steps
- Sanitized error messages

This project is designed to process supported session information locally. Contributions
