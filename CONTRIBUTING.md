# Contributing

Thanks for helping improve Codex Token Usage Monitor.

## Useful contributions

- Codex compatibility reports
- Parser and aggregation fixes
- Small reproducible tests
- Windows, macOS, and Linux startup improvements
- Documentation and usability improvements

## Bug reports

Please include your OS, Python version, Codex version if known, reproduction steps, expected behavior, and actual behavior.

## Privacy

Never submit API keys, private prompts, proprietary code, customer data, or sensitive session logs. Use sanitized examples.

## Pull requests

Keep changes focused, explain what problem is being solved, and avoid unnecessary dependencies.

This project is not an official OpenAI product.
